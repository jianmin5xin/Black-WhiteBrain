# 需求文档

## 1. 应用概述

### 1.1 应用名称
灰质-白质自举智能体网页自动化平台

### 1.2 应用描述
基于灰质-白质自举智能体架构的网页自动化Agent平台，实现网页元素识别、表单填写、操作流程记录、技能卡生成与管理。系统包含灰质层（低延迟执行）、白质层（慢速推理）、自举层（能力发现）、海马层（经验记忆）、元目标层（持续优化）、安全层（风险控制）六大核心层次。白质层接入AI大模型，实现真实失败分析与优化建议推理。提供可视化仪表盘和交互界面，支持用户登录、技能卡云端存储、历史记录持久化。用户可自行配置AI大模型API Key（BYOK），白质层优先使用用户配置的模型，无配置时回退到平台托管文心大模型。

## 2. 用户与使用场景

### 2.1 目标用户
需要自动化网页操作的用户，包括测试人员、运营人员、数据采集人员等。

### 2.2 核心使用场景
- 用户创建网页自动化任务，配置目标URL和操作序列
- 系统执行任务，识别网页按钮/表单元素，完成点击、填写、弹窗处理等操作
- 记录操作流程，生成可复用的技能卡
- 管理技能卡版本，调整参数优化执行效果
- 查看任务执行记录和失败分析
- 任务失败后，白质层AI推理分析失败原因并生成优化建议
- 浏览海马层经验记忆库，回放成功轨迹
- 监控安全层风险等级和动作日志
- 用户在设置页配置自己的AI大模型API Key，选择激活的模型提供商

### 3.4 任务管理

- 展示所有任务，包含任务名称、目标URL、状态、创建时间
- 支持查看任务详情
- 支持执行任务

#### 3.4.2 创建任务
- 输入任务名称
- 输入目标URL
- 配置操作序列（使用操作步骤编辑器）

#### 3.4.3 操作步骤编辑器
- 添加动作：点击、填写、等待、截图、弹窗处理
- 每个动作可配置目标元素选择器、参数
- 支持调整动作顺序
- 支持删除动作

#### 3.4.4 任务详情
- 展示任务基本信息（名称、目标URL、创建时间）
- 展示操作步骤列表
- 展示任务执行记录（执行时间、状态、耗时）
- 支持执行任务

#### 3.4.5 任务执行
- 点击执行后，系统开始执行任务
- 实时显示执行状态（运行中/成功/失败）
- 执行完成后，记录执行结果

#### 3.4.6 任务执行记录详情
- 展示任务执行记录的完整信息（执行时间、状态、耗时、执行步骤）

- 点击「白质层分析」按钮后，调用AI推理接口

- 展示失败类型分类（failure_type）
- 展示受影响的步骤列表（affected_steps）
- 展示优化建议列表（suggestions），每条包含优先级、建议操作、详细说明
- 展示参数补丁建议（param_patches），每条包含参数名、当前值、建议值、调整原因
- 展示推理置信度（confidence）
- 展示完整推理摘要（reasoning_summary）
- 支持「应用参数补丁」操作，更新技能卡参数
- 历史推理结果可重新查看

#### 3.4.8 失败复盘分析
- 展示失败任务的执行记录
- 白质层分析失败原因
- 生成优化建议

## 4. 业务规则与逻辑

### 4.1 技能卡生成规则
- 任务执行成功后，可从任务执行结果生成技能卡
- 技能卡包含感知面、执行面、可调参数、安全策略、指标
- 新生成的技能卡状态为「候选」

### 4.2 技能卡生命周期流转规则
- 候选 → 临时：用户手动变更或系统验证通过
- 临时 → 沙盒验证：进入沙盒环境测试
- 沙盒验证 → 灰质：沙盒测试通过，进入灰质层快速调用
- 灰质 → 成熟：执行成功率达到阈值
- 成熟 → 通用：适用于多种环境类型

### 4.3 白质层AI推理规则
- 任务执行失败后，用户可点击「白质层分析」按钮触发AI推理
- 白质层读取用户model_configs表，优先使用用户自配置的激活模型及对应API Key
- 若用户未配置或配置的模型调用失败，回退到平台托管文心大模型（INTEGRATIONS_API_KEY）
- 通过SSE流式接收推理结果，前端以打字机动画效果展示
- 推理结果包含：失败根本原因、失败类型分类、受影响步骤、优化建议列表、参数补丁建议、推理置信度、完整推理摘要
- 推理完成后，结果自动保存到task_runs表的analysis字段（JSON格式）
- 同时在memory_episodes表记录一条type='failure'的经验记录
- 推理建议存入task_runs.suggestions字段

### 4.4 模型配置规则
- 用户可配置多个模型提供商的API Key
- 仅允许激活一个模型提供商作为白质层默认模型
- API Key加密存储到model_configs表
- 已配置的Key在前端显示为脱敏格式（前4位+****+后4位）
- 文心一言为平台托管，无需用户配置，作为兜底模型

### 4.5 模型API调用规则
- DeepSeek、通义千问Qwen、OpenAI ChatGPT均兼容OpenAI Chat Completions格式
- Anthropic Claude需单独适配其API格式
- 白质层根据激活的模型提供商，调用对应的API接口

### 4.6 参数补丁应用规则
- 用户可在白质层推理结果中点击「应用参数补丁」
- 系统根据param_patches建议更新技能卡的可调参数
- 更新后生成新版本技能卡

### 4.7 失败复盘规则
- 任务执行失败后，白质层自动分析失败原因
- 生成优化建议，记录至海马层
- 用户可查看失败复盘分析结果

### 4.8 海马层记忆存储规则
- 任务执行产生经验记录（episode）
- 任务失败产生失败片段（failure）
- 任务成功产生成功轨迹（success）
- 参数调整产生参数补丁（parameter_patch）

### 4.9 环境自举规则
- 输入目标URL后，系统自动扫描网页
- 识别可感知的元素类型（按钮、输入框、下拉框、弹窗等）
- 识别可执行的操作类型（点击、填写、选择、等待等）
- 识别可获取的反馈信息（页面跳转、元素变化、弹窗提示等）
- 生成环境能力画像JSON

### 4.10 安全层风险控制规则
- 每个动作执行前，安全层评估风险等级
- 低风险动作：直接执行
- 中风险动作：记录日志后执行
- 高风险动作：拦截并记录至禁止动作记录

### 4.11 元目标评分规则
- 任务成功率 = 成功任务数 / 总任务数
- 效率 = 平均任务耗时的倒数
- 适应性 = 技能卡适用环境类型数量
- 安全性 = 1 - (高风险动作数 / 总动作数)

### 4.12 推理对比规则
- 推理对比页面仅展示type=failure且tags包含white_matter的记忆片段
- 对比视图支持选择同一任务的多条推理记录
- 差异高亮规则：新增内容标绿色，删除内容标红色，修改内容标黄色
- 演进轨迹视图按时间顺序展示参数变化，支持多参数叠加展示

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 用户未登录访问需登录页面 | 跳转至登录页 |
| 任务执行超时 | 标记任务失败,记录超时原因 |
| 目标URL无法访问 | 标记任务失败,记录网络错误 |
| 网页元素未找到 | 标记任务失败,记录元素选择器 |
| 技能卡参数非法 | 提示参数错误,不允许保存 |
| 环境扫描失败 | 提示扫描失败原因,允许重试 |
| 安全层拦截动作 | 记录至禁止动作记录,不执行 |
| 海马层记录查询为空 | 显示空状态提示 |
| 技能卡版本冲突 | 提示版本冲突,要求用户选择保留版本 |
| AI推理接口调用失败 | 提示推理失败原因,允许重试 |
| AI推理超时 | 提示推理超时,允许重试 |
| 参数补丁应用失败 | 提示应用失败原因,不更新技能卡 |
| 推理对比页面无可对比记录 | 显示空状态提示 |
| 选择不同任务的推理记录进行对比 | 提示仅支持同一任务的记录对比 |
| 演进轨迹视图参数数据不足 | 提示数据不足,无法生成轨迹图 |
| 用户输入的API Key格式错误 | 提示Key格式错误,不允许保存 |
| 用户配置的模型API调用失败 | 回退到平台托管文心大模型 |
| 用户未激活任何模型 | 默认使用平台托管文心大模型 |
| 用户激活的模型API Key失效 | 提示Key失效,回退到平台托管文心大模型 |
| 用户保存模型配置时网络异常 | 提示保存失败,允许重试 |
| 用户切换激活模型时已有推理任务运行中 | 提示当前有任务运行中,不允许切换 |

## 6. 验收标准

1. 用户完成邮箱密码注册并登录系统
2. 用户进入设置页的模型配置模块，配置DeepSeek的API Key（DEEPSEEK_API_KEY），保存成功后显示脱敏Key
3. 用户激活DeepSeek作为白质层默认模型
4. 用户在任务管理页面创建一个网页自动化任务,配置目标URL和操作序列(包含点击、填写、等待至少3个动作)
5. 用户执行该任务,任务执行失败,任务状态显示为「失败」
6. 用户在任务执行记录详情页点击「白质层分析」按钮,系统使用DeepSeek模型流式展示AI推理过程
7. 推理完成后,系统展示结构化分析结果,包含失败根本原因、失败类型、受影响步骤、优化建议列表、参数补丁建议
8. 用户点击「应用参数补丁」,系统更新技能卡参数并生成新版本
9. 用户在海马层记忆库查看该任务的失败片段记录
10. 用户在任务执行记录详情页重新查看历史推理结果
11. 用户在海马层记忆库进入「推理对比」标签页,筛选同一任务的多条推理记录
12. 用户选择至少2条推理记录,进入对比视图,查看root_cause、failure_type、suggestions、param_patches的差异高亮展示
13. 用户切换至演进轨迹视图,查看该任务的参数随时间变化的折线图
14. 用户返回设置页模型配置模块，删除DeepSeek的API Key，系统回退到平台托管文心大模型
